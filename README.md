# ⏳ TimeTravel Agency — Webapp Interactive

Webapp immersive et interactive pour une agence fictive de voyage temporel de luxe.  
Le site présente 3 destinations temporelles (Paris 1889, Crétacé -65M, Florence 1504) et intègre un agent conversationnel IA permettant aux visiteurs d’être conseillés et guidés.

## ✨ Features

### Fonctionnalités principales
- Landing page immersive (hero section avec visuel/vidéo en fond)
- Présentation de l’agence (concept, promesse, valeurs)
- Galerie interactive des destinations (cards cliquables + hover effects)
- Pages / modals détaillées pour chaque destination :
  - description immersive
  - activités recommandées
  - niveau de risque / sécurité
  - prix indicatifs
- Chatbot IA intégré (Voiceflow)
  - conseils personnalisés
  - réponses FAQ
  - informations sur les destinations et les tarifs
- Responsive design (mobile-first)

### Optionnel (selon avancement)
- Formulaire de réservation (destination + dates + voyageurs)
- Animations UI (micro-interactions / scroll animations)
- Quiz de recommandation personnalisé
